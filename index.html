GOOD TO KNOW

Frequently asked questions.

What is BuildPocket? +

BuildPocket is a browser-based knowledge organizer for saving webpages, sorting resources into collections, keeping notes, and storing reusable code snippets.

Where is my data stored? +

Your data is stored locally in your browser's extension storage. It is not automatically backed up or synced across devices. Avoid clearing extension data if you want to keep your saved resources.

Is BuildPocket available to install now? +

The public website is an introduction to BuildPocket. The official installation link will be added once the extension is published and its store listing is available.

Who is BuildPocket for? +

Students, developers, makers, and anyone who wants to organize useful links and reusable code in one place.
