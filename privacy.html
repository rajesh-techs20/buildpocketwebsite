BuildPocket Privacy Policy

Last updated: October 20, 2026

BuildPocket is a browser extension that helps users save webpages, organize links into collections, mark favorites, add notes, and manage reusable code snippets.

Information Stored

The current version stores saved links, webpage titles, collections, favorites, notes, and code snippets in the browser's local extension storage using chrome.storage.local. This information is intended to remain on the user's device.

Collection and Sharing

The current version is designed to store saved items locally and does not intentionally transmit this saved content to a BuildPocket server. BuildPocket does not sell users' saved information. This statement must be updated if the extension's data practices change.

User Control

Users can manage and delete saved items through the extension. Removing the extension or clearing its stored data may also remove locally stored information.

Children's Privacy

BuildPocket is a general-purpose productivity tool and is not specifically designed to collect personal information from children.

Changes to This Policy

This policy may be updated if BuildPocket's features or data practices change. The revision date above will be updated when changes are made.

Contact

For privacy questions, contact the BuildPocket developer using the contact information provided on the official BuildPocket website.
